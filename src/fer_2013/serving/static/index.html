FER-2013 emotion demo

Upload a photo. Faces are detected, classified into 7 emotions, and optionally explained with Grad-CAM++.

Images are processed in memory and never stored. Max 5 MB, JPEG/PNG/WebP. This model reaches about 71% accuracy on FER-2013 and reflects that dataset's biases; do not use it for decisions about people. API docs: /docs.
